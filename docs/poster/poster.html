AUTOMATION TRACK

CORVIN

Reducing manual downtime in data centers with an autonomous robot that replaces failed hard drives, with real-time operator control
The problem

Drives fail, people walk

Until a technician swaps the drive, the RAID array runs without redundancy.

Our solution

Corvin swaps them itself

It fetches a spare, swaps the drive and returns the failed one for RMA.
