07 · Software & vision

Every step checks its result before the next

Vision

  • AprilTags, 640 × 480 on the Pi 3
  • Tag pose steers the approach; funnel takes over under 260 mm
  • Bay tag corrects Z, up to 4 mm
  • Caddy ID checked before every pull

Mission

  • State machine on the Pi
  • Each move verified by a switch or the PLC; 2 retries, then FAULT
  • E-stop → re-home → resume or abort
  • Every transition time-stamped

Motion firmware

  • ESP32-S3, hardware step generation
  • TMC2209 set over UART
  • VMOT < 9 V → drivers off, re-init on return
  • 300 ms watchdog on velocity

IIoT dashboard

  • FastAPI + WebSocket, 5 Hz
  • Rack health, jobs, energy, camera
  • Delta PLC over Modbus TCP
  • Failed bay → job queued automatically
