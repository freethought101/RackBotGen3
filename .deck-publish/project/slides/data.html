08 · Data, vision & deployment

One Pi runs the whole stack — zero servers to pay for

Wiring

  • Camera (CSI) → Pi
  • Steppers + finger servos → ESP32
  • ESP32 ↔ Pi (USB) → dashboard (WebSocket)

Backend

  • FastAPI runs on the Pi itself
  • State machine writes to SQLite live
  • Dashboard reads the same file — no internet needed

Database

  • One SQLite file, 3 tables
  • jobs · events · caddies
  • A full event's data: well under 1 MB

Hosting

  • Primary: the Pi is the server — $0
  • Remote mirror (optional): Render / Cloud Run free tier
  • Always-on option: ≈ $5/mo (Railway)

Vision alignment

  • AprilTag pose at ≥ 8 fps
  • Bay tag corrects Z lift, ±4 mm
  • Caddy tag re-checked before every pull

Position tracking

  • Dead-reckoned from commanded steps
  • Open-loop steppers are repeatable
  • Each tag sighting clears the drift
